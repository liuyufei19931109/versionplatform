# 源码说明

开源预览包含 Java 21 / Spring Boot 后端、Vue 3 / TypeScript 前端、构建清单、依赖锁文件和本地测试。后端运行资源随 JAR 打包；前端由 Vite 生成静态资源。首版的实施顺序见[改造清单](../README.md)。

## 实例配置

- 首次初始化管理员需要设置 `RELEASE_BOOTSTRAP_ADMIN_PASSWORD`，至少 12 个字符、最多 72 个 UTF-8 字节。已有管理员保留当前状态。使用 MySQL 时须设置 `MYSQL_PASSWORD`。
- 镜像仓库、Git 组织、发布节点及凭据由部署方配置。默认使用本机构建，Webhook、小程序和生产自动合回默认关闭。
- 平台 Logo 默认为空。管理员上传的 PNG 会剥离附加元数据，保存到 `RELEASE_DATA_DIR` 下的 `branding/logo.png`。备份实例时请包含此目录。清除 Logo 后，登录页和导航恢复文字展示。
- 业务项目的移动构建参数由部署方定义。将签名资料与普通构建参数分开保存。

## 验证边界

本仓包含构建、发布准入、权限、版本小结、移动构建配置、运行脚本以及品牌设置的回归测试。测试样例使用虚构数据。源码基线和前端生产构建已在离线环境中验证。真实镜像推拉、SSH 部署与回滚须在独立测试环境验收。
